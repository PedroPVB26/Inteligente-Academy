# Inteligente-Academy

## Backend
<details><summary>Execução do Backend</summary>

Para execução do backend utilizando Docker, rode o comando:
`docker compose up`

Abra outro terminal e digite:
`docker exec -it inteligente-academy-db psql -U utfpr -d inteligenteacademy`
</details>

## Frontend
<details><summary>Execução do Frontend</summary>

Para rodar o frontend, digite:
`npm run dev`
